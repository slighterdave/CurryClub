# Server Cleanup Instructions for 13.49.111.162

This guide provides step-by-step instructions to clean up outdated files on your Ubuntu production server to ensure the deployed version matches the repository.

## Problem

The version running on the server may have outdated files that take precedence over new deployments, causing version mismatches.

## Solution: Complete Server Cleanup

Follow these steps on your Ubuntu server at **13.49.111.162**:

### Step 1: Connect to Your Server

```bash
ssh -i /path/to/your-key.pem ubuntu@13.49.111.162
```

### Step 2: Navigate to Project Directory

```bash
cd /home/ubuntu/CurryClub
```

### Step 3: Stop the Running Application

```bash
# If using PM2 (recommended)
pm2 stop curryclub
pm2 delete curryclub

# Or if running manually, press Ctrl+C in the terminal
```

### Step 4: Clean Up Old Build Artifacts

```bash
# Remove old build directories
rm -rf dist/
rm -rf Assets/  # Remove if exists (old build location)

# Remove node_modules to ensure clean install
rm -rf node_modules/

# Remove package-lock to ensure fresh dependency resolution
rm package-lock.json
```

### Step 5: Clean Up Old Documentation Files

These files were created during troubleshooting and are no longer needed:

```bash
# Remove outdated troubleshooting documentation
rm -f PM2_ERROR_FIX.md
rm -f SOLUTION_SUMMARY.md
rm -f TROUBLESHOOTING.md
```

### Step 6: Pull Latest Version

```bash
# Ensure you're on the main branch
git checkout main

# Pull the latest changes
git fetch origin
git pull origin main

# Verify what files are in the repository
git status
```

### Step 7: Clean Build and Deploy

```bash
# Install dependencies fresh
npm install

# Build the application
npm run build

# Verify the build succeeded
ls -la dist/
ls -la dist/assets/

# Start the application with PM2
pm2 start server.js --name curryclub

# Save PM2 configuration
pm2 save

# Check the status
pm2 status
pm2 logs curryclub --lines 20
```

### Step 8: Verify Deployment

```bash
# Run the verification script
./verify-deployment.sh
```

### Step 9: Test the Application

1. Open your browser and navigate to: `http://13.49.111.162:3000`
2. Clear your browser cache (Ctrl+Shift+Delete or Cmd+Shift+Delete)
3. Or do a hard refresh: Ctrl+Shift+R (or Cmd+Shift+R on Mac)
4. Test navigation and all features

## Quick Cleanup Script

You can create and run this cleanup script for faster execution:

```bash
cd /home/ubuntu/CurryClub

# Create cleanup script
cat > cleanup.sh << 'EOF'
#!/bin/bash

set -e

echo "🧹 Starting CurryClub cleanup..."

# Stop PM2
echo "Stopping PM2..."
pm2 stop curryclub || true
pm2 delete curryclub || true

# Clean up old files
echo "Removing old build artifacts..."
rm -rf dist/
rm -rf Assets/
rm -rf node_modules/
rm -f package-lock.json

# Remove outdated documentation
echo "Removing outdated documentation..."
rm -f PM2_ERROR_FIX.md
rm -f SOLUTION_SUMMARY.md  
rm -f TROUBLESHOOTING.md

# Pull latest code
echo "Pulling latest code..."
git checkout main
git fetch origin
git pull origin main

# Fresh install and build
echo "Installing dependencies..."
npm install

echo "Building application..."
npm run build

# Start PM2
echo "Starting PM2..."
pm2 start server.js --name curryclub
pm2 save

echo "✅ Cleanup complete!"
echo ""
echo "Run './verify-deployment.sh' to verify the deployment"

EOF

# Make it executable
chmod +x cleanup.sh

# Run it
./cleanup.sh
```

## Troubleshooting

### If PM2 shows "errored" status

```bash
# Check logs for the actual error
pm2 logs curryclub --lines 50

# Try running manually to see error
cd /home/ubuntu/CurryClub
node server.js
```

### If build fails

```bash
# Clear npm cache
npm cache clean --force

# Remove and reinstall
rm -rf node_modules package-lock.json
npm install

# Try build again
npm run build
```

### If port 3000 is in use

```bash
# Find what's using the port
sudo lsof -i :3000

# Kill the specific process (replace PID)
kill -9 PID
```
