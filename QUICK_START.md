# Quick Start Guide for Server Cleanup

This document provides the fastest way to clean up the production server at **13.49.111.162**.

## TL;DR - Quick Commands

```bash
# On your local machine, connect to the server
ssh -i /path/to/your-key.pem ubuntu@13.49.111.162

# Once connected, run these commands
cd /home/ubuntu/CurryClub
git pull origin main
chmod +x cleanup-server.sh
./cleanup-server.sh
```

That's it! The script will handle everything automatically.

## What the Cleanup Does

The `cleanup-server.sh` script will:

1. ✅ Stop the running PM2 process
2. ✅ Remove old build artifacts (`dist/`, `Assets/`)
3. ✅ Remove outdated documentation files
4. ✅ Clean install dependencies (removes `node_modules/`)
5. ✅ Pull latest code from GitHub
6. ✅ Install fresh dependencies
7. ✅ Build the application
8. ✅ Start the application with PM2

## After Cleanup

1. **Verify the deployment**:
   ```bash
   ./verify-deployment.sh
   ```

2. **Check PM2 status**:
   ```bash
   pm2 status
   pm2 logs curryclub
   ```

3. **Test in browser**:
   - Open: `http://13.49.111.162:3000`
   - Clear browser cache: `Ctrl+Shift+Delete` (or `Cmd+Shift+Delete` on Mac)
   - Or hard refresh: `Ctrl+Shift+R` (or `Cmd+Shift+R` on Mac)
   - Test all features and navigation

## Need Help?

If something goes wrong:

1. **Check the logs**:
   ```bash
   pm2 logs curryclub --lines 50
   ```

2. **Try manual build**:
   ```bash
   cd /home/ubuntu/CurryClub
   node server.js
   # This will show any errors directly
   ```

3. **Review detailed docs**:
   - [SERVER_CLEANUP.md](SERVER_CLEANUP.md) - Step-by-step cleanup
   - [DEPLOYMENT.md](DEPLOYMENT.md) - Full deployment guide

4. **Start fresh** (if needed):
   ```bash
   # Nuclear option - complete reinstall
   cd /home/ubuntu
   rm -rf CurryClub
   git clone https://github.com/slighterdave/CurryClub.git
   cd CurryClub
   npm install
   npm run build
   pm2 start server.js --name curryclub
   pm2 save
   ```
